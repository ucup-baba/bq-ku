# UI/UX Tahap 2 (Ruang Santri) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ruang Santri memakai gaya Clay Doodle Tahap 1: beranda padat dengan "Perlu dilengkapi", direktori ringkas, detail bertab CV/Berkas, dan wizard input/edit 4 langkah yang urut.

**Architecture:** Logika murni baru di `lib/santri/` (status berkas, filter, pengingat WA, validasi per langkah) diuji Vitest. Tampilan memakai komponen `components/ui/*` Tahap 1. `SantriForm.tsx` dipecah: seluruh state/logika dipindah ke hook `useSantriForm`, JSX dipindah ke 4 komponen langkah, lalu `SantriForm` menjadi komposisi wizard.

**Tech Stack:** Next.js 16, React 19, Tailwind 3.4, Phosphor, Vitest (jsdom), zod.

**Spec:** `docs/superpowers/specs/2026-09-23-ui-tahap-2-design.md`

## Global Constraints

- Sama dengan Tahap 1 (lihat `docs/superpowers/plans/2026-09-23-ui-tahap-1.md` §Global Constraints): ikon `/dist/ssr` di file server/universal; teks HP ≥12 px (`text-[10px]`/`text-[11px]` dilarang di file yang disentuh); input `text-base md:text-sm`; tidak ada ikon + teks "+"; tombol solid memakai `#0E9F54`; salinan Bahasa Indonesia; grid di HP wajib `grid-cols-1` (mencegah luapan horizontal oleh carousel/teks panjang).
- Logika OCR, batch scan, draft recovery, penjaga identitas dokumen, unggah foto, dan submit **tidak diubah perilakunya** — hanya dipindah.
- Data uji: hanya controller, satu santri, dibuat lewat aplikasi dan dihapus setelah verifikasi.
- Commit diakhiri `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Baseline test: 335 lulus, 5 dilewati.
